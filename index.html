━━━ 필수 준수 사항 ━━━

1. MD 내용 불변 원칙
   MD 파일의 텍스트, 구조, 데이터를 임의로 변경·추가·삭제하지 마.
   오직 있는 그대로 HTML로 변환해야 해. 어떤 이유로도 내용을 수정하면 안 돼.

2. UI/UX 개선 제안 제외
   MD 파일에 UI/UX 개선 제안 섹션이 포함되어 있더라도 HTML 변환 시 넣지 마.

3. 기능구분 ID 앵커 링크
   기능 구분 목록 테이블의 기능구분 ID(예: BIZ-001, WKP-001)를
   클릭 시 해당 그룹 섹션으로 이동하는 앵커 링크로 구성해.

4. 디자인 시스템 유지
   기존 HTML의 사이드바, 카드, 테이블, 컬러 시스템을 그대로 유지해.

5. 단일 메뉴 구성
   MD 파일 전체를 하나의 메뉴 항목으로 사이드바에 추가해.
   내부 세부 기능을 별도 사이드바 항목으로 나누지 마.

6. 업데이트 내역 갱신
   메뉴 01(업데이트 내역)에 오늘 날짜와 추가 내용을 기재해.
   최신순 5개 항목만 유지해. 6번째부터는 제거해.

7. 플로팅 버튼 유지 (필수)
   HTML 파일 우측 상단에 고정된 "컴포넌트 정의서 바로가기" 플로팅 버튼을
   절대 제거하거나 수정하지 마. 아래 코드를 사이드바 닫힘 태그와 메인 태그 사이에 그대로 유지해.
   URL: https://i-am-gyeong-jin.github.io/SafeNOW_v1_Component_Standard/

연결 기능 IDTBMG-002-01, TBMG-003-02
비고등록·수정 화면 공통 적용. 이미 그룹에 속한 일반 멤버는 임직원 목록에서 체크박스가 선택된 상태로 표시되며 중복 선택 불가. TBM 리더는 자동 멤버이므로 임직원 목록에 체크박스 선택·비활성화 상태로 표시되고, 우측에 "리더" 뱃지가 붙어 해제할 수 없다. 리더도 "선택된 인원" 수에 포함되어 카운트된다.
화면 설명
그룹 저장 완료 후(또는 그룹 수정 화면에서) 멤버 관리 영역의 [인원 추가] 버튼 클릭 시 표시되는 팝업이다. 좌측 "조직도" 트리에는 조직 단위별로 소속 인원수가 "조직명 (N)" 형태로 함께 표시된다. 우측 "임직원 목록"에서 체크박스로 복수의 인원을 선택하며, 각 행에는 이름과 함께 소속 조직·직급이 "조직명 · 직급" 형식으로 표시된다. TBM 리더는 목록 상단 또는 소속 위치에 체크·비활성화 상태로 노출되고 "리더" 뱃지가 붙는다. 하단 "선택된 인원" 영역에는 우측에 총 선택 인원수가, 아래에는 선택된 인원의 이름 태그(리더 제외 각 태그에 x 삭제 버튼 포함)가 표시된다. [선택 완료]를 클릭하면 멤버가 추가되고 팝업이 자동으로 닫힌다.
